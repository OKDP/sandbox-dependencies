# Changelog

## 0.3.0 (2026-08-28)


### ⚠ BREAKING CHANGES

* **kubocd-webhooks:** wrap the released KuboCD v0.3.2 chart
* an environment serving these values under context.platform no longer satisfies these packages. Move ingress, storageClass and certificateIssuers to the root of the Context. A platform that provisions its clients through DCR must now set anonymousDCR.enabled to true, which used to be the implicit behaviour.
* the .Context keys these packages used to read are gone. defaultDatabaseServer.settings.databases, defaultStorage, and the hiveMetastore, trino and jupyterHub blocks read by local-secrets-provider all move to package parameters, and a consumer of the database or of the object store now wires itself through a connectionRef. Every Release of these four packages has to be rewritten.
* **seaweedfs:** a Release of seaweedfs that relied on the admin123 password or on the okdp-seaweedfs-root-change-me root secret key no longer renders. Set both parameters explicitly, and rotate the values on any store that was deployed with the old defaults.
* **seaweedfs:** consume the neutral defaultStorage contract
* packages now publish to quay.io/okdp/platform-packages (no -v0.3 suffix)
